FlowMail for Windows

Create message batches with a guided workflow.

FlowMail helps you save a reusable message template, load a spreadsheet, map company, event, and hyperlink values, check real previews, and generate one output workbook. You can upload that workbook to a Google Drive folder you choose.

How it works

  1. Choose or create a saved template.
  2. Load your spreadsheet without changing the original file.
  3. Map the company name, event name, and hyperlink.
  4. Verify sample messages and record pairing.
  5. Generate one output file and, if connected, upload it to your selected Google Drive folder.

Why FlowMail asks for Google access

Google sign-in identifies your account. FlowMail reads Drive folder names and metadata so you can choose a destination. It creates the generated output file in the folder you select. FlowMail does not ask for your Google password.

FlowMail is a desktop application. Spreadsheet content and message generation are processed locally; the generated output is sent to Google Drive only when you run the upload action.
